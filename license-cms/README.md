# iCashbox License CMS

Один Vercel-проект: CMS открывается в браузере, а API лицензий доступно по `/api/license/*`. Данные хранятся в Neon Postgres.

## Что умеет

- карточки точек: адрес, контакт, срок, статус, количество касс;
- выпуск и смена ключей `ICB-…`;
- блокировка, продление и сброс касс при замене компьютера;
- онлайн-активация POS: `POST /api/license/activate`.

## Настройка Neon

1. Создайте бесплатный проект Neon и скопируйте строку подключения.
2. В Neon SQL Editor выполните содержимое [schema.sql](./schema.sql).

## Деплой Vercel

1. Импортируйте репозиторий в Vercel. Root Directory оставьте пустой, Framework Preset: **Other**.
2. Добавьте Environment Variables для Production и Preview:

   - `DATABASE_URL` — строка подключения Neon;
   - `ADMIN_TOKEN` — длинный случайный пароль админки;
   - `LICENSE_PEPPER` — другая длинная случайная строка для хеширования ключей.

   Сгенерировать значение: `node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"`.

3. Выполните Deploy. После публикации CMS доступна на корне домена, API — на `https://<ваш-домен>/api/license`.

Локально: `npm install`, затем `npx vercel dev` с заполненным `.env` на основе `.env.example`.

## Безопасность

`ADMIN_TOKEN` находится в сессии браузера лишь до закрытия вкладки. Не используйте общий компьютер. Ключи лицензий хранятся в Neon только как хеши; CMS показывает ключ только в момент создания или смены. В API используются серверные переменные Vercel — они не отправляются в браузер.

POS должен получать ключ через файл подключения, выпущенный CMS, и обращаться только по HTTPS к `/api/license/activate`.
