# iCashbox POS

Десктопная POS-система (касса) для кафе и магазинов на **Electron + React (Vite)** под Windows,
с онлайн-лицензированием через облачную CMS и офлайн-фолбэком по подписанному файлу лицензии.
Интерфейс на русском, целевой рынок — Таджикистан (валюта TJS, часовой пояс `Asia/Dushanbe`,
оплаты «Наличные / Alif / Dushanbe City»).

## Структура

| Папка | Назначение |
|---|---|
| `src/` | React-приложение кассы (`App.jsx`), экспорт Excel/PDF, стикеры |
| `electron/` | Главный процесс: печать, live-табло, лицензии, автозапуск |
| `license-cms/` | Vercel-проект: браузерная админка + API `/api/license/*` (Neon Postgres) |
| `public/` | Иконки, логотип чека, платёжные SVG |

## Запуск и сборка

```bash
npm install
npm run dev          # веб-предпросмотр (Vite, без Electron-функций)
npm run desktop      # сборка renderer + запуск Electron
npm run dist:win     # portable-сборка Windows в release/
```

В веб-предпросмотре десктопные функции (печать, live-табло, автозапуск, папка отчётов)
недоступны — они деградируют мягко, показывая подсказку «доступно только в portable-версии».

## Лицензирование (только онлайн)

Касса стартует **только по действующей онлайн-лицензии** (иначе показывает ошибку и закрывается):

- При первом запуске вводится ключ `ICB-…`, приложение обращается к
  `POST https://license-cms.vercel.app/api/license/activate` с уникальным `installationId`.
- CMS проверяет статус / срок / лимит устройств. Лицензия сохраняется локально
  (`online-license.icashbox.json`) и **переактивируется при каждом запуске** — без интернета касса не откроется.
- Срок действия ключа виден на экране входа и в разделе «База».
- Админ может сменить ключ: «База» → **«Сменить ключ лицензии»** удаляет активацию и перезапускает
  кассу на экран ввода нового ключа.

При активации задаются пароли администратора и кассира (стартовые — `0000`). Они засеваются в
единственный экран входа внутри кассы (роль + пароль). **Двойного входа нет.**

### CMS

См. [license-cms/README.md](license-cms/README.md): деплой на Vercel, переменные
`DATABASE_URL` / `ADMIN_TOKEN` / `LICENSE_PEPPER`, схема `schema.sql` (Neon Postgres).
Ключи лицензий хранятся только как SHA-256 хеши с «перцем».

## Возможности кассы

- Продажи, корзина, оплаты (нал/Alif/DS), смены и отчёты по сменам.
- Печать чеков 80 мм и товарных стикеров 57×40 мм (локальный агент на порту 8787).
- **Live-табло** (порт 8788): открывается на телефоне в той же сети; данные смены обновляются в реальном времени.
- Экспорт базы/меню/заказов в XLSX и JSON; выгрузка отчёта смены в выбранную папку.
- Автозапуск при входе в Windows (portable-версия).
- Роли admin/cashier с настраиваемым доступом к разделам.

## Профиль данных

Локальные данные кассы (лицензия, учётки, настройки) хранятся в `%APPDATA%/icashbox/`.
Сбросить активацию проще всего из приложения: «База» → «Сменить ключ лицензии». Вручную —
удалите `online-license.icashbox.json` и `operator-credentials.json`, после чего касса
покажет экран первичной настройки.
